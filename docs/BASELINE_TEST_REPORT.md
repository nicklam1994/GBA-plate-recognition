## 🔍 問題分析

### 1. 澳門本地牌完全無法檢測
**原因**：
- 黑底白字，模型訓練數據中黑底車牌樣本極少
- 澳門牌格式（MU-88-88）與內地牌格式差異大
- 車牌尺寸較小

**解決方案**：
- 增加澳門本地牌合成數據
- 微調模型以識別黑底白字車牌

### 2. 部分照片完全未檢測到車牌
**原因**：
- 車牌尺寸過小
- 拍攝角度問題
- 光照條件不佳
- 車牌反光或遮擋

**解決方案**：
- 增加小尺寸車牌訓練樣本
- 增加多角度訓練數據
- 優化檢測模型

### 3. 錯誤識別
**示例**：MEBX98 + 苏1D1
**原因**：
- 模型對香港牌和澳門牌格式不熟悉
- 字符識別錯誤

**解決方案**：
- 增加香港牌和澳門牌訓練數據
- 優化字符識別模型
