## 二、香港 374E 附表 4

### 第 1(a) 條 —— 排列

- 單行（圖 1），或
- **雙行：英文字母在上行、數目字在下行**（圖 1A）
- 自訂登記號碼雙行時每行最多 4 個字母／數字

### 第 1(b) 條 —— 字高

- 一般：**不得小於 8cm，不得大於 11cm**（80–110mm）
- 傷殘者車輛或電單車：5–11cm

### 第 2(b) 條 —— 顏色與標準

- 車頭：**白底黑字**；車尾：**黃底黑字**
- 牌面須符合 **B.S. AU 145a** 反光標準
- 白／黃底用反光物料，字母數字**不得**用反光物料

### 第 1(c) 條 —— 間距（自訂登記號碼）

- 字符之間：一般汽車 1–3.2cm；傷殘／電單車 0.2–2.5cm
- 空位：一般汽車 5.5–7cm

### 重要限制

**附表 4 沒有規定牌面總尺寸**（520×110、330×170 等）。
法例只管字高 80–110mm、排列、顏色、反光、間距。
市面常見的長牌 520×110、方牌 330×170 屬業界慣例／運輸署行政指引，非本法例條文。

## 五、軍車／武警／消防救援（GA 36 以外）

GA 36-2018 **不包含**這三類。它們分別依《軍車號牌管理規定》（2012 式）、
《中國人民武裝警察部隊車輛號牌管理規定》、《消防救援車輛號牌技術規範》。
本節依維基學院「2012 式軍車號牌」、國務院辦公廳 2018 年通知等公開資料整理，
**未取得一手標準原文**，可信度低於前三節。

### 解放軍（2012 式，2013-05-01 啟用）

```
外廓 440×140      白底      前牌：字頭、字頭號、間隔符紅色；序號黑色
                            後牌：僅字頭紅色，其餘黑色
結構：字頭 + 字頭號 + 間隔符 + 序號（小車/大車 5 位數字，摩托車 4 位）
```

**字頭是紅色英文字母，不是漢字**：

| 字頭 | 含義 |
|------|------|
| V | 北京衛戍區 |
| W | 中央軍委各部門直屬單位 |
| Z | 中央軍委及四總部直屬單位 |
| L | 陸軍 |
| H | 海軍 |
| K | 空軍 |
| WJ | 武警部隊 |

「軍／海／空」這類漢字字頭屬 1984 式以前的天干地支體系，早已廢止。

### 武警部隊（2013／2019 式）

```
外廓 440×140（大型車尾牌雙行方形）
前牌：WJ + 省份漢字簡稱 + 警種 為紅色，其餘黑色
後牌：僅 WJ 紅色
格式：WJ京·12345  或  WJ京·1234J
```

舊「97 式」的 `WJ18-12345`（兩位數字省碼）已停用；
現行用**漢字省份簡稱**（WJ粵、WJ京）。
消防部隊 2018 年轉制後已陸續停用 WJ 牌。

### 國家綜合性消防救援隊伍（2019 起）

依國務院辦公廳 2018 年通知：

```
汽車號牌 480×140    白底黑字，配紅色漢字「應急」
摩托車號牌 220×140  單只號牌
8 位字符 = 省級行政區簡稱 + 所屬救援隊伍代號 + 序號 + 紅色「應急」
例：粵A1234應急
前牌隊伍代號紅色、後牌黑色
```

**尾字是「應急」兩字（簡體），不是「消」或「險」。**
號牌中央間隔符為消防專屬紅色徽標（五角星＋消防斧＋水帶），非普通圓點。

### 實作對照

| 項目 | 實作 | 依據 | 可信度 |
|------|------|------|--------|
| 軍車 | `MAINLAND_MILITARY` 白底、前 2 字符紅色 | 維基學院 | 中 |
| 武警 | `MAINLAND_ARMED_POLICE` 白底、前 3 字符紅色 | 汽車之家／百度經驗 | 中 |
| 消防 | `MAINLAND_RESCUE` 白底、尾 2 字「應急」紅色 | 國務院辦公廳通知 | 較高 |
